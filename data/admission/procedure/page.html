    Application Procedure

    1. Create an account by clicking "Register".
    2. Fill up User Registration Form to create username and password.
    3. Enter the website and view application periods.
    4. Select program you wish to apply.
    5. Confirm application by clicking on "Apply for this program".
    6. Complete the form by clicking "Finish & Save".
    7. Pay application fee USD 150 by money transfer to the following account number:
      Bank Name BNI
      Branch UI Depok
      Account Name Universitas Indonesia
      Account Number 127.300.0035
      Swift Code BNINIDJAUID
  • Upload the application fee payment receipt.
  • Check your application status by logging in your application account.

    • Notes

    • Make sure the email address you register is in use. To view or edit your application, login by using the same username and password.
    • We will verify your payment and you should get a notification on this account after your payment is successfully verified.
