    Registration Form

    Pendaftaran admission.ui.ac.id adalah pendaftaran khusus untuk pendaftar Warga Negara Asing (WNA).
    Pendaftaran ini bukan pendaftaran untuk Kelas Internasional.
    Jika Anda adalah Warga Negara Indonesia, silakan melakukan pendaftaran di SIMAK UI (http://penerimaan.ui.ac.id/).
    International Students Admission (admission.ui.ac.id) only accepts registration specifically from International Applicants (non-Indonesian citizens).
    If you are an Indonesian citizen, please register using SIMAK UI (http://penerimaan.ui.ac.id/)
